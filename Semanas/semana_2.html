Semana 2

Flexbox: Concepto, Contenedores, Elementos de las Paginas Web con Diseño Responsivo

Logro de Aprendizaje:

Al final de la sesión, el estudiante conoce sobre Flexbox: concepto, contenedores, elementos de las paginas Web con diseño responsivo, teniendo en cuenta sus principios y normativas y poder aplicarlo en su carrera.

Flexbox:

Flexbox o tambien conocido como Flexible Box Layout es un modelo de diseño de CSS que sirve para organizar elementos en filas o columnas de forma flexible y adaptable.

Esto permitira conpaginar diversos elementos de una pagina de forma unidimensional.

Contenedores Flexbox:

Un contenedor Flexbox permite organizar los elementos que están dentro de él de manera flexible, pudiendo controlar su dirección, posición, alineación y distribución del espacio.

  • display: flex;

Dirección del contenido:

Determina en qué dirección se colocan los elementos dentro del contenedor:

  • row: Elementos de izquierda a derecha.
  • row-reverse: Elementos de derecha a izquierda.
  • column: Elementos de arriba hacia abajo.
  • column-reverse: Elementos de abajo hacia arriba.

Alineación y justificación:

Permite controlar dónde se ubican los elementos dentro del contenedor, tanto en el eje principal como en el eje secundario.

  • justify-content: Distribuye los elementos en el eje principal.
  • align-items: Alinea los elementos en el eje secundario.

Flexibilidad de los elementos:

Permite que los elementos se adapten al espacio disponible dentro del contenedor asignado.

  • flex: 1;
