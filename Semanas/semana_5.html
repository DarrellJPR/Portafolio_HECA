Semana 5

los preprocesadores CSS y sus ventajas

Logro de Aprendizaje:

Al finalizar la sesión de aprendizaje el estudiante conoce sobre los procesadores CSS, sus ventajas que tiene estos en las paginas web, para poder aplicarlos en los casos prácticos.

Preprocesadores CSS:

Un preprocesador CSS es una herramienta que amplía el CSS tradicional con funciones de lenguajes de programación, permitiendo compilar ese código en un archivo CSS estándar que los navegadores web pueden leer.

Modelos de Preprocesadores:

  • LESS

    • Se mantiene principalmente en proyectos antiguos o que dependen del ecosistema de componentes antiguos. Su adopción en nuevos desarrollos es casi nula.

  • SASS

    • Sigue siendo el estándar de la industria para grandes frameworks y proyectos heredados que requieren lógica compleja o funciones matemáticas avanzadas.

  • STYLUS

    • Ha quedado prácticamente obsoleto en la comunidad moderna debido a la falta de mantenimiento de sus herramientas y su ecosistema cerrado en Node.js.

Caracteristicas:

  • Agrega Variables:

    • Permiten guardar valores como colores o tamaños de fuente para reutilizarlos en todo el código.

  • Anidación de Selectores:

    • Permite meter los selectores unos dentro de otros imitando la estructura HTML.

  • Mixins

    • Bloques de código reutilizables que pueden recibir datos y generar estilos complejos.

  • Uso de estructuras de control

    • Permite el uso de estructuras de control y bucles como si de un lenguaje de programación consistiera.

Ventajas:

  • Mantenimiento sencillo:

    • Si cambias el valor de una variable, se actualiza en todo el sitio web automáticamente.

  • Ahorro de tiempo:

    • Puedes modificar rapidamente colores, tamaños, estilo de letras. Escribes menos código repetido y organizas mejor tus proyectos grandes.

  • Funciones Avanzadas:

    • Possen funciones avanzadas como si fuera un lenguaje de programación, que permiten agilizar el desarrollo.
