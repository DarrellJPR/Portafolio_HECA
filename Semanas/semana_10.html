Semana 10

Transiciones y transformaciones: conceptos, propiedades y aplicaciones en las páginas web

Logro de Aprendizaje:

Al finalizar la sesión de aprendizaje el estudiante conoce sobre Transiciones y transformaciones: conceptos, propiedades y aplicaciones con animaciones en las páginas web, para poder aplicarlos en los casos prácticos.

Introducción a las Transiciones y Transformaciones:

Las transiciones y transformaciones son herramientas de CSS que permiten modificar la apariencia y posición de los elementos de una página web, creando efectos visuales que mejoran la interacción con el usuario.

Las transiciones permiten realizar cambios progresivos entre diferentes estados de un elemento, mientras que las transformaciones modifican su posición, tamaño, orientación o inclinación.

Ambas funcionalidades pueden combinarse para conseguir efectos visuales más dinámicos, como botones que cambian de tamaño, imágenes que giran o tarjetas que se desplazan al interactuar con ellas.

Transiciones CSS:

Las transiciones CSS permiten controlar la velocidad con la que cambia una propiedad de un elemento cuando pasa de un estado visual a otro.

Sin una transición, los cambios de las propiedades generalmente se aplican de manera inmediata. Al utilizar transiciones, el navegador calcula los estados intermedios para conseguir un cambio gradual.

  • Cambio de color:

    • Permite modificar progresivamente el color de fondo o del texto de un elemento.

  • Cambio de tamaño:

    • Permite realizar modificaciones graduales en las dimensiones de determinados elementos.

  • Cambio de posición:

    • Permite conseguir desplazamientos visuales progresivos cuando cambian las propiedades correspondientes.

  • Cambio de opacidad:

    • Permite controlar gradualmente la transparencia de los elementos.

Propiedades de las Transiciones:

CSS dispone de diferentes propiedades que permiten controlar cómo se desarrollan las transiciones y cuánto tiempo tardan en completarse.

  • transition-property:

    • Especifica cuáles son las propiedades CSS que tendrán una transición cuando cambien sus valores.

  • transition-duration:

    • Define el tiempo que tarda en completarse una transición. Se puede expresar en segundos o milisegundos.

  • transition-timing-function:

    • Determina cómo se distribuye la velocidad durante la transición. Permite utilizar diferentes funciones de aceleración.

  • transition-delay:

    • Establece el tiempo que debe transcurrir antes de que comience la transición.

  • transition:

    • Es una propiedad abreviada que permite configurar conjuntamente las principales características de una transición.

Transformaciones CSS:

Las transformaciones CSS permiten modificar visualmente un elemento mediante cambios en su posición, dimensiones, orientación e inclinación.

Se realizan principalmente mediante la propiedad transform, que modifica el espacio de coordenadas del elemento sin alterar directamente el flujo normal del documento.

Las transformaciones pueden aplicarse de manera individual o combinarse para conseguir diferentes resultados visuales.

También pueden combinarse con las transiciones CSS para conseguir que los cambios de posición, escala o rotación se realicen progresivamente.

Tipos de Transformaciones:

  • Traslación (Translate):

    • Permite desplazar un elemento desde su posición original hacia otra ubicación, utilizando desplazamientos horizontales, verticales o en profundidad.

  • Rotación (Rotate):

    • Permite girar un elemento alrededor de un punto determinado, modificando su orientación.

  • Escalado (Scale):

    • Permite aumentar o disminuir las dimensiones visuales de un elemento, tanto de manera uniforme como de forma independiente en sus ejes.

  • Inclinación (Skew):

    • Permite inclinar un elemento horizontal o verticalmente, modificando sus ángulos y su apariencia visual.

  • Transformaciones 3D:

    • Permiten trabajar con movimientos, rotaciones y escalados en un espacio tridimensional, incorporando profundidad a los elementos.

Origen de las Transformaciones:

La propiedad transform-origin permite establecer el punto desde el cual se realiza una transformación sobre un elemento.

De manera predeterminada, las transformaciones utilizan como referencia el centro del elemento. Sin embargo, este punto puede modificarse para conseguir diferentes efectos visuales.

  • Origen horizontal:

    • Permite establecer el punto de referencia en el eje horizontal del elemento.

  • Origen vertical:

    • Permite determinar el punto de referencia en el eje vertical.

  • Origen en profundidad:

    • En las transformaciones tridimensionales, también se puede establecer una referencia sobre el eje de profundidad.

Aplicaciones de las Transiciones y Transformaciones:

  • Botones interactivos:

    • Permiten modificar el color, tamaño o posición de los botones cuando el usuario interactúa con ellos.

  • Tarjetas de contenido:

    • Se utilizan para crear efectos de elevación, desplazamiento o ampliación en tarjetas informativas.

  • Imágenes:

    • Permiten aplicar efectos de acercamiento, rotación y cambios de apariencia cuando el usuario interactúa con una imagen.

  • Menús de navegación:

    • Facilitan la incorporación de efectos visuales al seleccionar o recorrer las opciones de navegación.

  • Galerías de imágenes:

    • Permiten incorporar desplazamientos y transformaciones para mejorar la presentación de los elementos visuales.

  • Elementos interactivos:

    • Ayudan a proporcionar respuestas visuales cuando el usuario realiza determinadas acciones dentro de la página.

Consideraciones al utilizar Transiciones y Transformaciones:

  • Uso adecuado:

    • Se deben utilizar estos efectos cuando aporten información visual o mejoren la interacción, evitando incorporarlos sin una finalidad.

  • Rendimiento:

    • Es recomendable priorizar transformaciones y cambios de opacidad cuando sea posible, ya que generalmente permiten obtener animaciones más fluidas.

  • Accesibilidad:

    • Se deben considerar las preferencias de los usuarios que necesitan reducir los movimientos visuales mediante las opciones de accesibilidad.

  • Duración:

    • Los tiempos de transición deben ser adecuados para que los cambios sean perceptibles sin retrasar las interacciones.

  • Compatibilidad:

    • Es importante comprobar el comportamiento de las propiedades utilizadas en los navegadores donde se visualizará la página.
