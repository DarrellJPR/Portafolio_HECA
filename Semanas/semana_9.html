Semana 9

Animaciones web: introducción, tipos, propiedades y aplicaciones de las animaciones en las paginas web

Logro de Aprendizaje:

Al finalizar la sesión de aprendizaje el estudiante conoce sobre Animaciones web: introducción, tipos, propiedades y aplicaciones de las animaciones en las páginas web, para poder aplicarlos en los casos prácticos.

Introducción a las Animaciones Web:

Las animaciones web son efectos visuales que permiten modificar progresivamente la apariencia o el comportamiento de los elementos de una página web a lo largo del tiempo.

Mediante CSS y JavaScript se pueden crear movimientos, cambios de tamaño, rotaciones, desplazamientos, modificaciones de colores y efectos de aparición o desaparición.

En CSS, las animaciones permiten establecer diferentes estados visuales de un elemento y controlar cómo cambia entre ellos. Esto ayuda a mejorar la presentación y proporciona información visual sobre las acciones que realiza el usuario.

Tipos de Animaciones Web:

  • Transiciones CSS (Transition):

    • Permiten realizar cambios graduales entre dos estados de un elemento cuando cambia alguna de sus propiedades CSS. Por ejemplo, al pasar el cursor sobre un botón, su color puede modificarse progresivamente.

  • Animaciones CSS (@keyframes):

    • Permiten definir una secuencia de cambios mediante fotogramas clave. Se pueden establecer diferentes estados utilizando porcentajes o las palabras from y to, controlando la duración y las repeticiones de la animación.

  • Animaciones mediante JavaScript:

    • Permiten crear y controlar animaciones mediante código JavaScript. Una de las herramientas disponibles es la Web Animations API, que permite reproducir, pausar, invertir y modificar la velocidad de las animaciones.

  • Animaciones activadas por interacción:

    • Son efectos que se producen como respuesta a las acciones del usuario, como pasar el cursor sobre un elemento, presionar un botón o interactuar con determinados componentes de la página.

Propiedades de las Animaciones CSS:

CSS dispone de diferentes propiedades para configurar el comportamiento de una animación. Entre las principales se encuentran:

  • animation-name:

    • Especifica el nombre de la animación que se desea utilizar, el cual debe coincidir con una regla @keyframes.

  • animation-duration:

    • Establece cuánto tiempo tarda en completarse un ciclo de la animación. Se expresa normalmente en segundos (s) o milisegundos (ms).

  • animation-delay:

    • Determina cuánto tiempo debe esperar la animación antes de comenzar.

  • animation-iteration-count:

    • Indica cuántas veces se repetirá la animación. Puede utilizar el valor infinite para repetirla continuamente.

  • animation-direction:

    • Define la dirección de reproducción, permitiendo que la animación avance normalmente, retroceda o alterne entre ambas direcciones.

  • animation-timing-function:

    • Controla la velocidad de cambio durante la animación. Algunos valores son ease, linear, ease-in y ease-out.

  • animation-fill-mode:

    • Establece cómo se aplican los estilos de la animación antes de comenzar o después de finalizar.

  • animation-play-state:

    • Permite establecer si una animación está ejecutándose o permanece pausada.

Fotogramas Clave (@keyframes):

La regla @keyframes permite establecer los diferentes momentos de una animación y definir los estilos que tendrá un elemento en cada uno de ellos.

Se pueden utilizar los valores from y to para indicar el estado inicial y final, o porcentajes para establecer estados intermedios.

Por ejemplo, una animación puede comenzar con un elemento ubicado en su posición original, desplazarse durante el proceso y finalizar en una posición diferente.

Aplicaciones de las Animaciones Web:

  • Interacción con botones:

    • Permiten mostrar cambios visuales cuando el usuario pasa el cursor sobre un botón o realiza una acción, proporcionando una respuesta visual.

  • Menús de navegación:

    • Se utilizan para mostrar y ocultar opciones de menú mediante efectos de desplazamiento, aparición o cambios de apariencia.

  • Presentación de contenido:

    • Facilitan la aparición progresiva de imágenes, textos y otros elementos para organizar visualmente la información.

  • Indicadores de carga:

    • Permiten representar visualmente procesos que requieren tiempo, como la carga de información o la espera de una respuesta.

  • Realce de elementos:

    • Ayudan a destacar determinados componentes de una página, como notificaciones, mensajes importantes o elementos interactivos.

  • Experiencia de usuario:

    • Pueden facilitar la comprensión de las interacciones y hacer que la navegación resulte más clara, siempre que se utilicen de manera moderada.

Consideraciones al utilizar Animaciones:

  • Rendimiento:

    • Es importante evitar animaciones innecesariamente complejas que puedan afectar la fluidez de la página.

  • Accesibilidad:

    • Se debe considerar a las personas que prefieren reducir el movimiento en pantalla. CSS dispone de la consulta prefers-reduced-motion para adaptar las animaciones a esta preferencia.

  • Duración:

    • Los efectos deben tener una duración apropiada para que el usuario pueda percibirlos sin retrasar innecesariamente la interacción.

  • Uso moderado:

    • Las animaciones deben tener un propósito dentro de la página y no distraer al usuario del contenido principal.
