Semana 3

Grid Layout, conceptos y frameworks de Front, Row y Column

Logro de Aprendizaje:

Al finalizar la sesión de aprednizaje el estudiante conoce Grid Layout, conceptos y frameworks de Front, Row y Column para poder aplicarlos en los casos prácticos.

Grid Layout:

CSS Grid Layout es un sistema de CSS que se utiliza para crear una disposición ordenada de elementos en una página web. CSS Grid Layout es una de las herramientas más poderosas para lograr esto. Permite a los diseñadores y desarrolladores definir áreas en una cuadrícula y colocar elementos en esas áreas, facilitando un diseño más flexible y responsivo.

Caracteristicas:

  • Diseño bidimensional:

    • Maneja dos ejes a la vez (horizontal y vertical), a diferencia de Flexbox que funciona en una sola dimensión.

  • Control de pistas:

    • Permite definir el tamaño y la cantidad de filas y columnas.

  • Espaciado nativo:

    • Añade separación entre filas y columnas de manera limpia sin necesidad de manipular márgenes manualmente.

  • Posicionamiento por líneas y áreas:

    • Los elementos pueden ubicarse mediante líneas de referencia o agruparse en áreas nombradas para estructurar la página completa.

  • Adaptabilidad:

    • Permite reordenar o cambiar la estructura de la cuadrícula según el tamaño de la pantalla sin modificar el código HTML.

Propiedades del contenedor Grid:

  • display: grid - Convierte un elemento en un contenedor Grid.
  • grid-template-columns - Define las columnas.
  • grid-template-rows - define las filas.
  • grid-template-areas - Permite crear áreas con nombres.
  • gap - Establece el espacio entre filas y columnas.
  • column-gap - Establece el espacio entre columnas.
  • row-gap - Establece el espacio entre filas.
  • justify-items - Alinea los elementos horizontalmente dentro de sus celdas.
  • align-items - Alinea los elementos verticalmente dentro de sus celdas.
  • justify-content - Distribuye la cuadrícula horizontalmente dentro del contenedor.
  • align-content - Distribuye la cuadrícula verticalmente dentro del contenedor.


Propiedades de los elementos Grid:

  • grid-column - Indica en qué columnas se ubicará un elemento.
  • grid-row - Indica en qué columnas se ubicará un elemento.
  • grid-area - Permite colocar un elemento en un área determinada.
  • justify-self - Alinea individualmente un elemento horizontalmente.
  • align-self - Alinea individualmente un elemento verticalmente.
